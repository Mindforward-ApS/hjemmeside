# Miwa i 3D (Blender)

- rig4.py: hendes billede pustet op til en 3D-krop med skelet; renderer klippene i public/video/miwa.
- Kør: blender -b -P rig4.py -- clips  (ONLY=idle,walkR for enkelte klip). Kræver cut-glad.png, cut-glad-dil.png,
  lids-full.png, alpha.npy og depth.npy i samme mappe (laves af forarbejdet i scratchpad; se git-historikken).
- rig.py / rig2.py / rig3.py er de tidligere 2D-versioner.
